--------------------------------------------------

Task 2.3 - Load Factor and Rehashing Design:
-------------------------------------------
- Target Load Factor: alpha_max = 0.75 for separate chaining (or alpha_max = 0.50 if open addressing were used).
  At alpha = 0.75 in separate chaining, expected successful search is 1 + alpha/2 = 1.375 probes, and unsuccessful
  search is alpha = 0.75 probes.
- Initial Table Size: For N = 40,000 and alpha = 0.75, M_min = 40,000 / 0.75 = 53,333.
  Choose the nearest prime M = 53,353 to eliminate arithmetic step cycles.
- Dynamic Rehashing Design:
  When (count + 1) / capacity > 0.75:
    1. Allocate new table of size M_new = next_prime(2 * M_old).
    2. Iterate through all buckets of the old table.
    3. Re-hash each member key: new_idx = hash(key) % M_new.
    4. Splice node into new bucket list (O(N) amortized total work).
    5. Deallocate old bucket pointer array.

Key Observation:
In separate chaining, probes grow linearly with alpha (only 1.45 probes even at 90% load).
In linear probing, unsuccessful probes explode quadratically as 0.5 * (1 + 1/(1-alpha)^2), reaching > 48 probes
at alpha = 0.90 due to long primary cluster formation.
